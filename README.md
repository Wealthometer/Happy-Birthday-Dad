# Happy Birthday, Dad 🎂

A birthday tribute to Bishop Olumide Hajoh, by Wealth Hajoh.

## Run it
    npm install
    npm run dev

## Edit it
All words and photos are in `src/content.js`. Photos are in `public/photos`.
- Journey section: replace the placeholder chapters with real years and moments.
- Lessons section: make each one a real memory.
- Music: a built-in music-box "Happy Birthday" plays after he taps "Open your gift".
  To use your own song, put an mp3 in `public/music/` and set `musicSrc` in content.js.

## Put it online (free)
    npm run build
Then drag the `dist` folder onto https://app.netlify.com/drop — or push to GitHub
and import the repo on Vercel. Send Dad the link.
